copy_rust

Консольная игра на C++17 для Windows. Запусти .exe и играй прямо в терминале — установка не нужна.

Скачать v5.5 Скачать v5.5 BETA Исходный код

Что внутри

Консольный интерфейсВсё работает в терминале, без окон и лишних зависимостей.
Файл настроекПараметры игры лежат в config_cop_rast.json — открой в любом редакторе.
Исходники всех версийКод на C++17 собирается через CMake, старые версии лежат в папке versions.

Версии

Список берётся прямо из папки versions в репозитории — новые версии появляются здесь сами.

Как запустить

Скачай v5.5.exe, положи рядом config_cop_rast.json и запусти файл двойным кликом или из командной строки. Если Windows показывает предупреждение SmartScreen, нажми «Подробнее» → «Выполнить в любом случае».

Сборка из исходников

git clone https://github.com/chelicpubg228-design/copy_rust.git
cd copy_rust
cmake -S . -B build
cmake --build build

Нужны CMake и компилятор C++ (например, MSVC или MinGW).
