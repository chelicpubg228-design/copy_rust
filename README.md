# copy_rust

Консольная игра на выживание для Windows, написанная на C++17. Исследуй карту, добывай ресурсы, крафти инструменты и броню, охоться на зверей и не умри от голода, жажды или усталости.

## Быстрый старт

1. Скачай `v5.5.exe` и положи в отдельную папку.
2. Запусти двойным кликом или из командной строки.
3. Введи имя и выбирай пункты меню по номеру.

> Если Windows SmartScreen выдаёт предупреждение, нажми «Подробнее» → «Выполнить в любом случае».

Игра сохраняется сама в файл `config_cop_rast.json` рядом с `.exe`.

```

=============menu===========
x = 0
y = 0

user~$
```

## Суть игры

Ты появляешься в точке (0, 0) на координатной плоскости с каменным топором и факелом. Ходишь по карте, осматриваешься, находишь деревья, камень, железо, серу, ягоды, ткань и зверей. Из добытого делаешь железный топор и кожаную броню. Любое действие тратит еду, воду и энергию, поэтому нужно вовремя есть и спать.

## Правила

| Показатель | Старт | Что происходит |
|------------|-------|----------------|
| Здоровье (HP) | 100 | Падает от зверей. При 0 — смерть. Восстанавливается само, если еда и вода не ниже 70: +10 HP за ход, стоит по 10 еды и воды |
| Еда | 100 | Тратится на действия. При 0 — смерть |
| Вода | 100 | Тратится на действия. При 0 — смерть |
| Энергия | 100 | Тратится на добычу, поиск и бегство. Смерть при −100. Сон: 10 секунд, +75 |

Смерть сбрасывает ресурсы, инструменты, броню и позицию. Имя остаётся.

## Управление

Главное меню: вводи номер пункта и нажимай Enter. Основная игра идёт в **свободном режиме** (пункт 10):

| Клавиша | Действие |
|---------|----------|
| `w` / `s` | шаг по оси x вперёд / назад |
| `d` / `a` | шаг по оси y вперёд / назад |
| `e` | осмотреться: с некоторым шансом найдёшь ресурс или зверя (потом `y` — добывать или драться, `n` — пропустить) |
| `f` | поесть |
| `` ` `` | консоль |
| `q` | в главное меню с сохранением |

Мир делится на три зоны: ближняя (до ±10 000 по обеим осям), средняя (до ±1 000 000) и дальняя. У каждой зоны свои случайные точки ресурсов и зверей.

## Ресурсы

| Ресурс | Чем добывать |
|--------|--------------|
| Дерево (большое, среднее, малое) | каменный или железный топор |
| Камень | каменный топор или железная кирка |
| Железо | каменный топор или железная кирка |
| Сера | каменный топор или железная кирка |
| Ягоды | руками (+5 за раз) |
| Ткань | руками (+5 за раз) |
| Кости, мясо, кожа, ткань | с убитых зверей |

Месторождения добываются, пока не иссякнут. Прочность: каменный топор 100, железный топор 140, кирка 150, каждый удар снимает 1.

## Крафт (пункт 5)

| Предмет | Стоимость |
|---------|-----------|
| Каменный топор | 5 дерева + 1 камень |
| Железный топор | 5 дерева + 5 железа |
| Нитки | 5 ткани (получаешь 5 ниток) |
| Кожаный шлем | 3 ткани + 3 нитки + 3 кожи |
| Кожаный нагрудник | 5 ткани + 6 ниток + 10 кожи |
| Кожаные поножи | 4 ткани + 5 ниток + 4 кожи |
| Кожаные ботинки | 3 ткани + 3 нитки + 5 кожи |

## Звери и бой

Встретив зверя, выбираешь: убежать (минус энергия, еда и вода) или драться.

| Зверь | HP | Урон за раунд |
|-------|----|---------------|
| Олень | 80 | 1 |
| Волк | 100 | 10 |
| Медведь | 120 | 15 |
| Мышь | — | 5 (убить нельзя) |

| Оружие | Урон |
|--------|------|
| Факел | 10 |
| Каменный топор | 15 |
| Железный топор | 25 |
| Железная кирка | 35 |

## Броня

Надевается пунктом 6, снимается пунктом 7. Повышает максимальное здоровье: шлем +10, нагрудник +20, поножи +15, ботинки +5. В боях изнашивается.

## Еда (пункт 17)

- Ягоды (5 штук): еда +4, вода +8.
- Мясо (5 штук): еда +10, вода +2.

## Консоль и настройки

- **Настройки** (пункт 11): `n` — сменить имя, `r` — удалить сохранение и начать заново, `h` — справка, `q` — выход.
- **Консоль** (пункт 12): `help`, `stat`, `status`, `tp` (телепорт по x и y), `user_change`, `setting`, `cls`, `exit`.
- Мини-игра (пункт 15): угадай число от 1 до 100 за 10 попыток.

## Сборка из исходников

Только Windows (используются `windows.h` и `conio.h`). Нужны CMake, компилятор C++17 и библиотека [nlohmann/json](https://github.com/nlohmann/json). `CMakeLists.txt` ищет её в папке из переменной окружения `INCLUDE_VCPKG_for_me`, поэтому укажи там путь к `include` твоего vcpkg.

```bash
vcpkg install nlohmann-json
git clone https://github.com/chelicpubg228-design/copy_rust.git
cd copy_rust
cmake -S . -B build
cmake --build build --config Release
```
